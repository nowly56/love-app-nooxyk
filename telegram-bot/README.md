# Telegram bot + Mini App

> Старая заготовка из предыдущей итерации. Текущий фронтенд `src/web` работает локально и не обращается к этому серверу. Бэкенд отложен; эта заготовка не является готовой системой авторизации или хранения. Актуальная инструкция — в корневом README.md.

Сервер не хранит состояние интерфейса: он запускает бота, показывает кнопку открытия web-приложения и проверяет подпись `Telegram.WebApp.initData`.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`.
2. Создайте бота через `@BotFather` и вставьте токен в `TELEGRAM_BOT_TOKEN`.
3. Укажите публичный HTTPS-адрес web-приложения в `TELEGRAM_WEB_APP_URL`.
4. Запустите из корня проекта: `npm run bot:start`.

Для клиента Expo задайте:

- `EXPO_PUBLIC_TELEGRAM_API_URL` — публичный адрес этого bot-сервера;
- `EXPO_PUBLIC_TELEGRAM_BOT_USERNAME` — username бота без `@`.

Web App должен работать по HTTPS. В Telegram Mini App автоматически передаются Telegram-пользователь и параметр приглашения из ссылки `?startapp=...`.
