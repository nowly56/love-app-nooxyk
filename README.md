# Love Archive — Telegram Mini App

Готовое веб-приложение для открытия внутри Telegram и через обычный браузер. Включает альбом, памятные даты, поиск, избранное, настройки и резервное копирование. Сейчас фотографии и настройки хранятся локально в браузере; серверной синхронизации между пользователями и устройствами пока нет.

## Быстрый запуск

Нужен Node.js 22.18 или новее.

```sh
npm ci
npm run web
```

Проверки и сборка:

```sh
npm run typecheck
npm test
npm run build:web
```

## Публикация на Railway

В репозитории уже есть `railway.json`: Railway соберёт Mini App, запустит Telegram-бота и будет отдавать веб-интерфейс с того же HTTPS-домена. `/health` используется для проверки состояния сервиса. Сборка должна включать `dist`; локально эта папка исключена из Git и создаётся на этапе деплоя.

1. Создайте пустой репозиторий на GitHub и загрузите в него файлы проекта. Не добавляйте `node_modules`, `.expo`, `dist` и `.env`.
2. В Railway создайте проект из этого GitHub-репозитория и дождитесь создания сервиса.
3. В настройках сервиса Railway создайте публичный домен (HTTPS).
4. В разделе **Variables** задайте `TELEGRAM_BOT_TOKEN` — токен, полученный у `@BotFather`. Можно также указать `TELEGRAM_WEB_APP_URL=https://ваш-домен.up.railway.app`; если переменную не задать, приложение использует `RAILWAY_PUBLIC_DOMAIN` от Railway.
5. Убедитесь, что в Railway запущен только один экземпляр сервиса: бот использует long polling Telegram.
6. После успешного деплоя откройте чат с ботом и отправьте `/start`. Сервер настроит команду и кнопку меню, открывающую Mini App.

Railway читает локальный `railway.json`: команда сборки — `npm run build:web`, запуска — `npm run start:railway`. Секреты задаются через **Variables**, а не в файлах репозитория. После смены адреса приложения обновите `TELEGRAM_WEB_APP_URL` и передеплойте сервис.

## Переменные окружения

В корне есть локальный `.env` для разработки и безопасный шаблон `.env.example`. В `.env` нужно вставить свой токен:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_WEB_APP_URL=https://ваш-публичный-домен
TELEGRAM_WEBHOOK_SECRET=
TELEGRAM_USE_WEBHOOK=false
```

Файл `.env` уже добавлен в `.gitignore`. Он предназначен только для локальной машины и не должен попадать в GitHub. Значения Railway задаются отдельно в интерфейсе **Variables**. Настоящий токен не включён в проект — его выдаёт BotFather для принадлежащего вам бота.

## Что пока не подключено

- Данные не синхронизируются и не хранятся на Railway: локальный архив находится в хранилище WebView/браузера конкретного устройства.
- Совместные альбомы, привязка пары и серверное хранение фотографий требуют отдельного бэкенда и базы данных.
- Проверка Telegram `initData` не заменяет серверные сессии и пока не подключена к интерфейсу.

## Структура

- `src/entry.web.ts` → `App.web.tsx` → `src/web/LoveArchive.tsx` — веб-интерфейс Mini App.
- `src/web/telegram.ts`, `src/web/useTelegramEnvironment.ts` — адаптация интерфейса к Telegram Web App SDK.
- `src/web/models.ts`, `src/web/repository.ts`, `src/web/storage.ts` — модели и граница между интерфейсом и локальным IndexedDB-хранилищем; позднее адаптер можно заменить API.
- `telegram-bot/server.mjs` — команды бота, проверка здоровья процесса и раздача собранного фронтенда.
- `railway.json` — конфигурация сборки и запуска на Railway.
- `tests/archive.test.mjs` — проверки дат, архива, восстановления и валидации резервной копии.

Исходные Expo/native-экраны и старые Supabase-заготовки сохранены, но не используются текущим Telegram Mini App.
